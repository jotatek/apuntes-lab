01

Introducción al Lenguaje de Marcas y Desarrollo Web

Un lenguaje de marcas es un sistema de codificación que combina texto con etiquetas o anotaciones para definir la estructura, la presentación o la información de un documento. A diferencia de los lenguajes de programación tradicionales, los documentos estructurados en HTML no son compilados, sino que son interpretados directamente por los navegadores web en cualquier sistema operativo.

El desarrollo web se sustenta sobre tres tecnologías fundamentales:

HTML

HyperText Markup Language. Es el esqueleto del sitio web: aporta la estructura lógica del contenido y los cimientos sobre los que se construye la web.

CSS

Cascading Style Sheets. Representa la apariencia visual o «piel»: aplica estilos y adapta la maqueta a diferentes pantallas (responsive).

JavaScript

Es el «cerebro»: aporta interactividad y dinamismo mediante código ejecutado en el navegador o en el servidor con Node.js.

Tipos de páginas web y perfiles profesionales

Las páginas web pueden ser estáticas (archivos HTML, CSS y JS fijos que muestran siempre el mismo contenido sin base de datos) o dinámicas (disponen de motores de base de datos, lógica de servidor y sesiones de usuario únicas).

El conocimiento profundo de HTML es indispensable para múltiples perfiles profesionales del sector digital, como maquetadores, desarrolladores Frontend, Backend y FullStack, así como para especialistas en SEO, analistas web, diseñadores UI/UX y expertos en accesibilidad.

02

Estructura Básica y Metadatos de un Documento HTML

Esqueleto estándar HTML5

Todo documento web debe cumplir con las reglas sintácticas del lenguaje: anidamiento correcto de elementos, cierre de etiquetas y estructuración del documento. El esqueleto fundamental es: 

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi primera página web</title>
</head>
<body>
    <!-- Aquí se incluye el contenido visible -->
</body>
</html>
  • <!DOCTYPE html>: declaración obligatoria en la primera línea que especifica el estándar HTML5 y evita el modo no estándar del navegador.
  • <html>: elemento raíz que delimita todo el documento y establece el idioma mediante el atributo lang.
  • <head>: cabecera técnica con metadatos e información interna no visible en pantalla.
  • <body>: cuerpo del documento que alberga todos los elementos visibles (texto, imágenes, tablas).

Metadatos clave en <head>

Dentro de la etiqueta <head> se configuran parámetros críticos para buscadores y navegadores:

  • <title>: define el título que aparece en la pestaña del navegador y es decisivo para la indexación en motores de búsqueda (SEO).
  • <meta charset="UTF-8">: establece la tabla de codificación universal para representar correctamente tildes y caracteres especiales.
  • <meta name="viewport">: ajusta escala y dimensiones para garantizar la adaptabilidad en dispositivos móviles.
  • Etiquetas adicionales: permiten indicar descripciones (description), palabras clave (keywords), autoría (author), icono de pestaña (<link rel="icon">) y color de la interfaz móvil (theme-color).
  • HTML5 Boilerplate: plantilla de inicio estándar recomendada para estructurar carpetas de proyecto y organizar recursos (assets) como imágenes, archivos CSS y scripts JS.
03

Etiquetas de Texto, Formateo y Espaciado

Jerarquía de encabezados <hx>

Las etiquetas de encabezado van desde <h1> hasta <h6> y establecen el nivel de importancia jerárquica del contenido:

  • <h1>: título principal del documento, el texto más relevante. Debe incluirse únicamente uno por página para optimización SEO.
  • <h2> a <h6>: estructuran temas, secciones, apartados y subapartados de forma lógica sin saltarse niveles de la jerarquía.

Formateo de texto y citas

El marcado textual ofrece distintas etiquetas semánticas y de estilo:

  • Párrafos (<p>): elementos de bloque que delimitan fragmentos de texto agregando márgenes superiores e inferiores por defecto.
  • Énfasis: <strong> para denotar importancia o peso semántico (negrita) y <em> para énfasis tónico (cursiva).
  • Estilos tradicionales: <b> (negrita), <i> (cursiva), <tt> (mecanografía), <sup> (superíndice), <sub> (subíndice), <big> e <small>.
  • Bloques de código y citas: <blockquote> para citas textuales en bloque, <cite> para referenciar obras creativas y <code> para presentar código con tipografía monoespaciada.

Manejo de espacios en blanco

HTML comprime automáticamente múltiples espacios consecutivos o saltos de línea del código en un solo espacio. Para controlar el flujo se utilizan:

  • <br />: etiqueta vacía para forzar un salto de línea manual.
  • <wbr />: oportunidad de salto de línea opcional dentro de palabras extensas.
  • <pre>: bloque preformateado que respeta los espacios en blanco e indentaciones originales del código.
04

Etiquetas Semánticas de Estructura y Agrupación

Uso de etiquetas semánticas en HTML5

En versiones anteriores se abusaba del uso genérico de la etiqueta <div> («divitis»). HTML5 introdujo etiquetas semánticas que aportan significado estructural, mejorando notablemente el SEO y la accesibilidad para lectores de pantalla y bots de búsqueda. 

+-------------------------------------------------------+
|                       <header>                        |
|                         <nav>                         |
+-------------------------------------------------------+
|           <main>            |         <aside>         |
|  <section>     <article>    |                         |
+-----------------------------+-------------------------+
|                       <footer>                        |
+-------------------------------------------------------+
  • <header>: cabecera superior que suele contener el logotipo y elementos comunes de presentación.
  • <nav>: sección que engloba el menú o enlaces principales de navegación del sitio web.
  • <main>: contenedor del contenido principal y único del documento web.
  • <section>: agrupa contenidos temáticos relacionados que habitualmente llevan su propio encabezado.
  • <article>: representa una entidad de contenido independiente y autónoma (entradas de blog, noticias, productos).
  • <aside>: alberga información secundaria, bloques laterales, enlaces relacionados o publicidad.
  • <footer>: pie de página destinado a avisos legales, datos de copyright y navegación secundaria.

Elementos de agrupación genéricos y líneas separadoras

  • <div>: etiqueta de bloque genérica utilizada para agrupar elementos visuales sin aportar valor semántico directo.
  • <span>: etiqueta de línea genérica empleada para aislar fragmentos de texto e identificar partes a las que aplicar estilos CSS o interactividad JS sin alterar el flujo.
  • Regla de contenido: una etiqueta de línea puede contener otras etiquetas de línea, pero nunca puede encerrar etiquetas de bloque.
  • <hr>: elemento de bloque que representa una separación temática o regla horizontal entre contenidos.
Recuerda: usar etiquetas semánticas mejora el SEO, la accesibilidad y el mantenimiento del código frente al abuso de <div>.
05

Listas e Hipervínculos

Tipos de listas

Organizan la información en formatos estructurados:

  1. Listas No Ordenadas (<ul>): para elementos donde el orden no es relevante (ej. ingredientes, características).
  2. Listas Ordenadas (<ol>): para secuencias jerárquicas o procesos paso a paso.
    • Los elementos individuales de ambas listas se definen con la etiqueta <li>.
  3. Listas de Definición (<dl>): para glosarios o diccionarios, asociando términos (<dt>) con sus definiciones (<dd>).
  4. Listas Anidadas: permiten incluir una lista dentro de otra, colocándose siempre dentro de un elemento <li>.

Hipervínculos (<a>)

Los enlaces permiten la navegación entre documentos o secciones mediante la etiqueta <a>. Sus atributos clave incluyen:

  • href: URL de destino, ruta local, sección interna (#id) o dirección de correo (mailto:). Debe escribirse con sintaxis limpia, sin espacios ni caracteres especiales.
  • target: dónde se abrirá el enlace; _blank en una nueva pestaña y _self en la pestaña actual.
  • download: fuerza la descarga del recurso vinculado (requiere estar alojado en un servidor).
  • hreflang: especifica el código de idioma del documento enlazado.
06

Elementos Multimedia y Tablas

Inserción de imágenes

Las imágenes se integran mediante la etiqueta <img src="ruta_imagen" /> en formatos livianos como PNG, JPEG o GIF. Es posible convertir imágenes en enlaces envolviéndolas en etiquetas <a>. Para agrupar imágenes de forma semántica se utiliza la etiqueta <figure> en combinación con un pie descriptivo <figcaption>.

Tablas HTML

Permiten estructurar información en cuadrículas de filas y columnas:

  • <table>: contenedor general de la tabla.
  • <tr>: define cada una de las filas de la tabla.
  • <th>: encabezado de columna con texto resaltado y centrado por defecto.
  • <td>: celda estándar de datos dentro de una fila.
  • Fusión de celdas: se gestiona mediante los atributos colspan="n" (combinar columnas horizontalmente) y rowspan="n" (combinar filas verticalmente).
07

Formularios e Interacción con el Usuario

Los formularios (<form>) son mecanismos esenciales que permiten capturar información introducida por el usuario y enviarla a un servidor backend para su procesamiento.

Atributos principales de <form>

  • action: URL del servidor o destino que procesará los datos enviando el formulario.
  • method: especifica el método HTTP de transferencia de datos (GET o POST).
  • enctype: define el tipo de codificación (necesario multipart/form-data para adjuntar archivos).
  • Otros atributos: target, autocomplete, novalidate y accept-charset.

Comparativa: métodos HTTP GET vs. POST

Diferencias entre GET y POST
Característica Método GET Método POST
Envío de datos Concatena los datos visibles en la URL tras el símbolo ? separados por &. Envía la información de forma oculta en el cuerpo de la petición.
Capacidad Limitado (aproximadamente 500 bytes). Permite grandes volúmenes de información.
Archivos adjuntos No permite adjuntar ficheros. Sí admite el envío de documentos o archivos adjuntos.
Uso principal Formularios de consulta o búsqueda (ej. Google). Creación, edición, borrado o envío de datos sensibles (CRUD).

Controles de entrada (<input> y otros)

La etiqueta <input> ajusta su comportamiento según el atributo type:

  • Texto y contraseña: type="text" (cajas de texto corto) y type="password" (oculta los caracteres).
  • Selección única: type="radio" (requiere que los elementos del grupo compartan el mismo atributo name).
  • Selección múltiple: type="checkbox" (permite marcar varias opciones simultáneamente).
  • Nuevos controles HTML5: type="number", type="range", type="date", type="color", type="file", type="email".
  • Otros elementos: <textarea> para textos largos, <select> para menús desplegables, <datalist> para autocompletado y botones <button> de envío (submit) o reinicio (reset).
Consejo: utiliza siempre POST con enctype="multipart/form-data" cuando el formulario incluya subida de archivos, y valida los datos tanto en cliente como en servidor.

Práctica: Simulador, Minijuegos y Herramientas de Estudio

Pon a prueba lo que has leído en los siete temas anteriores. Todas las preguntas salen de la teoría de este compendio, y tu progreso (aciertos, rachas, tarjetas y capítulos leídos) se guarda en este navegador.

¿Cómo gano XP?
  • Cada acierto da XP según su dificultad: fácil 10 · media 15 · difícil 25 (los atributos y los temas 6 y 7 son más difíciles).
  • Escribir la etiqueta vale más que elegirla (×1,5, y más si juegas con tiempo). Detectar errores, ordenar el esqueleto y el Playground también puntúan.
  • Cada pista te quita un 25 % del XP de esa pregunta.
  • Saltar solo da 1 XP; fallar o agotar el tiempo, 0.
  • Las flashcards (te evalúas tú) dan un 60 % del XP.
  • Cada vez que subes de nivel desbloqueas una insignia nueva.
Método recomendado: lee un tema, haz el test de ese tema, repasa los fallos con las flashcards y termina con el simulador en modo difícil (escribir la etiqueta con tiempo).
