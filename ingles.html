Emailing · Futuro y escritura

En inglés hay tres formas principales de hablar del futuro. La elección depende de si hablas de un plan, de una cita ya organizada o de una decisión espontánea.

A) Be going to + infinitivo

Para planes e intenciones que ya tienes en la cabeza antes de hablar.

sujeto + am/is/are + going to + verbo en infinitivo

I'm going to take part in a convention next month.
→ Voy a participar en una convención el mes que viene.

She is going to call the IT department.
→ Va a llamar al departamento de IT.
  • Negativa: I'm not going to open that email.
  • Pregunta: Are you going to reply?

B) Present Continuous con valor de futuro

Para planes ya organizados, con hora, día o persona concreta (una cita, una reunión…).

sujeto + am/is/are + verbo con -ing

We're having a meeting in the afternoon.
→ Tenemos una reunión por la tarde (ya está fijada).

I'm meeting the client at 5.
→ He quedado con el cliente a las 5.
💡
Truco: be going to = intención. Present Continuous = ya está organizado (hay hora, lugar, gente).

C) Will + infinitivo

Para decisiones espontáneas, promesas y ofertas. Igual para todas las personas.

sujeto + will + verbo en infinitivo

OK, I'll look at it this morning.
→ Vale, lo miro esta mañana (decisión en el momento).

I'll send you the file.
→ Te enviaré el archivo (promesa/oferta).

Negativa: will not = won't
I won't have time to deal with it then.

Resumen rápido

FormaSe usa paraEjemplo
be going toPlanes e intencionesI'm going to learn Excel.
Present ContinuousPlanes organizados (hora, lugar)I'm meeting her at 6.
willDecisiones espontáneas, promesas, ofertasI'll help you.

Estructura de un email

  1. Subject — asunto breve y claro.
  2. Saludo — Dear Mr Smith, / Hi Jane, / Hello team,
  3. Motivo — I'm writing to… / I'd like to…
  4. Cuerpo — información principal.
  5. Despedida — Best regards, / Kind regards, / Yours sincerely,
  6. Firma — nombre, cargo y datos de contacto.

Frases útiles

Para abrir

I'm writing to ask about… / I'd like to know if…

Para adjuntar

Please find attached… / I've attached the file.

Para cerrar

I look forward to hearing from you. / Let me know if you need anything else.

Para disculparse

I'm sorry for the delay. / Apologies for the confusion.

Formal vs. informal

  • Formal: Dear Mr Smith, · I would like to… · Yours sincerely,
  • Informal: Hi Jane, · Can I…? · Best,

Phishing: cómo reconocerlo

  • Remitente desconocido o dirección sospechosa.
  • Enlaces o adjuntos que no esperabas.
  • Urgencia: «Your account will be closed», «Immediate action required».
  • Errores de ortografía o gramática.
  • Te piden contraseña, datos bancarios o información personal.
💡
Reporta siempre el email con el botón Report phishing. Nunca respondas ni pinches los enlaces.

Consejos de búsqueda eficaz

  1. Usa palabras clave descriptivas, no frases largas.
  2. Usa comillas para frases exactas.
  3. Usa el signo menos para excluir términos.
  4. Añade el país, el año o el formato para acotar.
  5. Usa site: si solo quieres un dominio.
  6. Comprueba la fuente y la fecha.
  7. No te fíes solo de la IA: verifica siempre.
  8. Usa search tools (idioma, país, fecha).

Conditionals · Los cuatro condicionales

Un conditional es una frase con dos partes: la if-clause (la condición) y la main clause (el resultado). En inglés hay cuatro tipos principales; cada uno se usa para un grado distinto de realidad.

If clause  +  main clause      (o al revés: Main clause + If clause)

If it rains,   I will stay at home.
I will stay at home   if it rains.
💡
Si empiezas por la parte del if, se pone coma. Si empiezas por la parte principal, no se pone coma.

0) Zero Conditional · verdades generales

Para cosas que siempre son verdad: leyes físicas, rutinas, hechos científicos.

If + present simple,  present simple

If you heat water to 100 °C, it boils.
→ Si calientas el agua a 100 °C, hierve.

If I drink coffee at night, I can't sleep.
→ Si tomo café por la noche, no puedo dormir.

1) First Conditional · futuro posible

Para situaciones reales o posibles en el futuro y sus consecuencias. Es el «si pasa esto, pasará esto otro».

If + present simple,  will + infinitivo

If we use online tools, it will be easier to work together.
→ Si usamos herramientas online, será más fácil trabajar juntos.

If I filter the emails, it will be easier to find them.
→ Si filtro los correos, será más fácil encontrarlos.

Negativa:  If you don't sort the emails, it won't be easy.
⚠️
Error típico: después de if NO se pone will. ✅ If I finish early, I'll call you. ❌ If I will finish early, I'll call you.

2) Second Conditional · hipótesis

Para situaciones hipotéticas, improbables o imaginarias en el presente o futuro. Muchas veces se traduce en español con el subjuntivo («si yo fuera…», «si tuviera…»).

If + past simple,  would + infinitivo

If I won the lottery, I would travel around the world.
→ Si ganara la lotería, viajaría por todo el mundo.

If I were you, I would apply for that job.
→ Si yo fuera tú, solicitaría ese trabajo.

Negativa:  If I didn't have a car, I wouldn't go to work.
💡
Con el verbo be, en el Second Conditional se prefiere were para todas las personas: If I were… / If he were…

3) Third Conditional · pasado imposible

Para situaciones que ya no se pueden cambiar: hipótesis sobre el pasado, arrepentimientos, reproches. Es el «si hubiera…, habría…».

If + past perfect,  would have + past participle

If I had studied, I would have passed the exam.
→ Si hubiera estudiado, habría aprobado el examen.

If she had known, she would have helped us.
→ Si ella lo hubiera sabido, nos habría ayudado.

Negativa:  If we hadn't missed the train, we wouldn't have been late.
  • Pasado perfecto: had + participio (had studied, had seen).
  • Participio: acabado en -ed (regulares) o 3ª columna (irregulares: seen, gone, done).

Mediation

Mediar es explicar algo con tus propias palabras a alguien que no lo entiende: un compañero, un cliente, un familiar. En un examen de mediación se valora que:

  • Expliques el significado con palabras sencillas.
  • Adaptes el registro al interlocutor.
  • Pongas ejemplos y comparaciones.
  • No copies literalmente el texto original.

Ejemplo de mediación: «Phishing is a type of email scam. Criminals pretend to be a company you know, and they ask for your password or bank details. If you get an email like that, don't click any links and report it.»
